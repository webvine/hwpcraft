# HwpCraft 기능 확장과 완료 기준

현재 공개 버전은 0.19이다. 로컬 Launcher 실행본은 통합 검증을 통과한 버전으로 갱신한다. 아래 목록은 순서 제안이며 각 단계는 필요한 만큼 나눠 출시한다. 모든 편집은 HwpCraft 공통 엔진에서 구현하고 UI·CLI·MCP가 같은 경로를 사용한다. 하위 라이브러리가 제공하지 않는 모델·편집·조판·출력은 HwpCraft 자체 계층에서 보완한다.

| 순서 | 기능군 | 필요한 작업 |
|---|---|---|
| 1 | 편집·출력 정합성 | 공개 액션/인자 어댑터, 문맥 주소, 동적 번호, 출력 일치, 실문서 회귀 세트 |
| 2 | 표 | 중첩 표 직접 편집, 여러 쪽 표·반복 머리행, 계산/정렬/자동채우기 범위 |
| 3 | 쪽·양식 | 구역·첫쪽/홀짝 머리말, 바탕쪽, 각주/미주 조판, 정밀 인쇄 |
| 4 | 검토 | 새 메모·답글·작성자·상태, 변경 추적·수락/거절, 구조 비교/병합 |
| 5 | 언어·참조 | 맞춤법·빠른 교정·사용자 사전, 낱말 한자, 서식 상용구, 동적 필드·차례·색인 |
| 6 | 고급 개체 | 새 차트, 수식 편집, 글맵시, 그림 효과, 일반 폼과 임베디드 개체 |
| 7 | 제품 기능 | 여러 문서/분할 보기, 자동 복구·성능, 기록/재생, 다중 포맷·서명·협업 |

0.15는 문단 이동과 형광펜 공통 출력을 구현했다. 0.16은 공개 인자 일부, 주소 기반 중첩 표 편집·생성/삭제, 본문 메모 CRUD, 본문 동적 번호와 HWPX 번호 형식 보존을 추가한다. 각 기능군의 나머지 옵션과 문맥은 계속 구현·검증한다.

기능마다 읽기/보존, 신규 생성, 편집, 저장/재열기, 화면/PNG/PDF 출력을 나눠 지원 범위를 기록한다. 완료 판단에는 일반·경계 입력, 지원 문맥, 인자 단위/기본값, undo/redo, 실패 시 보존, UI/CLI/MCP, HWP/HWPX 왕복, 조판/출력 검증이 필요하다. 명령 등록 수나 테스트 통과 수만으로 전체 완성도를 판정하지 않는다.
