# HwpCraft 0.10

## 버전 체계

사용자 표시 버전은 `VERSION` 파일의 `0.10`입니다. 이후 `0.11`, `0.12`처럼 `x.xx`로 증가합니다. 창 제목·CLI·MCP·설치 스크립트·Launcher·로컬 패키지는 이 값을 사용합니다. Cargo 패키지의 필수 SemVer 값은 내부적으로 `0.10.0`입니다.

## 마우스 휠 확대/축소

- 문서 위에서 Ctrl+휠 위: 확대 / Ctrl+휠 아래: 축소.
- 오른쪽 아래 배율 표시 위에서는 Ctrl 없이 휠만으로 확대/축소.
- 일반 문서 휠은 스크롤. 메뉴·대화상자 위에서는 문서 배율을 바꾸지 않습니다.
- 배율 범위는 10–500%. 미세한 픽셀 휠 입력도 누적합니다.
- 문서 위 확대/축소는 스크롤 가능한 범위에서 포인터 아래의 문서 위치를 유지합니다. 메뉴와 대화상자 크기는 바뀌지 않습니다.
- 배율 변경은 문서를 수정하거나 실행 취소 기록을 만들지 않습니다.

## 검증

`wheel_zoom.rs`의 egui 이벤트 검사는 Ctrl+휠/일반 휠 구분, 위치 유지, GUI 배율 불변, 문서 수정 상태 불변, 최소·최대 배율, 대화상자/리본 제외, 미세 픽셀 누적, 가로 휠 제외, 배율 표시 위 휠을 검사합니다.

로그: `logs/0.10-tests.log`, `logs/0.10-clippy.log`, `logs/0.10-build.log`, `logs/0.10-install.log`.

최종 결과: 전체 테스트 127개 통과, Clippy `-D warnings` 통과. CLI와 MCP initialize 버전 `0.10` 확인. runtime·Launcher·로컬 `0.10` 패키지 설치 완료.

Windows 실제 창에서 일반 문서 휠 스크롤과 배율 표시 위 휠로 90% → 132% → 90% 확대·축소를 확인했습니다. Ctrl+휠은 위 egui 이벤트 회귀 검사로 확인했습니다. 실제 캡처: [휠 확대](../output/table-interaction/0.10-wheel-zoom-in.png).
