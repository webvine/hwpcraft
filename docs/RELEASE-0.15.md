# HwpCraft 0.15 — 문단 이동과 공통 형광펜 출력

이 버전은 기본 편집과 출력 경로를 개선한다. 전체 기능의 동등성 달성을 뜻하지 않는다.

- 공통 캐럿 엔진에 `prev_paragraph_end`를 추가했다. 앞 문단 끝으로 이동하며 첫 문단에서는 처음으로 이동한다. 본문/일반 셀과 선택 확장에 적용된다.
- `MovePrevParaEnd`, `MoveSelPrevParaEnd`가 새 동작을 사용한다. 공개 이름 `MoveDocBegin`, `MoveDocEnd`, `MoveSelDocBegin`, `MoveSelDocEnd`를 추가했고 기존 긴 이름도 유지한다. 문서 정보의 기존 부분 대응 별칭도 생성 표에 복원했다.
- HwpCraft 자체 SVG 보완 경로가 형광펜을 그린다. 데스크톱/미리보기·CLI/MCP PNG·PDF 저장/인쇄용 PDF가 이 경로를 공유한다. 화면 전용 이중 덧그리기는 제거했다.
- 형광펜이 있는 PDF도 인쇄용 표시 정책과 클릭 가능한 하이퍼링크를 유지한다. 형광펜이 없는 PDF는 기존 출력 경로를 유지한다. 출력 시 화면용 20,000자 탐색 제한을 적용하지 않는다.
- 형광펜 좌표는 문서 세대별로 재사용하고 편집/되돌리기 후 다시 계산한다. PDF 내보내기는 기존 저장 경로·미저장 상태를 바꾸지 않는다.
- 블록 저장은 선택에 맞춰 형광펜 구간을 보존한다. 문단 끝의 네이티브 위치도 보정해 전체 문단·부분 선택의 HWP/HWPX 저장에서 형광펜이 사라지지 않도록 했다.
- MCP 초기화 응답의 버전 문자열에서 줄바꿈을 제거했다.
- Launcher는 버전별 설치 경로를 등록한다. 이전 버전 창이 실행 중이어도 새 버전을 설치하고 새 실행 경로로 전환할 수 있다.

형광펜 좌표 지원은 본문과 1단계 표 셀이다. 중첩 셀·머리말/글상자/주석 문맥, 본문 자동 쪽 번호 렌더, 복잡한 조판과 고급 검토 기능은 여전히 남아 있다. 형광펜의 알파 합성은 기존 화면 표현을 유지하며 한글의 모든 조판/색 합성 옵션과 동등하다고 판정하지 않는다.

회귀 검사는 문단 경계·빈 문단·Unicode scalar·셀·선택·기존 별칭, 형광펜 HWP/HWPX 왕복·undo/redo, MCP PNG 실제 픽셀과 PDF 생성을 대상으로 한다. 로컬 검증 결과와 실행 영수증은 분석 출력 폴더에 보관한다.
