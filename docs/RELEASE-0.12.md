# HwpCraft 0.12 — 문서 스크롤 레이아웃

사용자 제공 비교 화면(2026-10-24 19:00:51 / 19:01:18)을 기준으로 문서 탐색 UI를 수정했습니다.

- 문서 ScrollArea의 기본 자동 축소 때문에 스크롤바가 종이 폭에 붙던 문제를 해결했습니다. 문서 영역은 남은 창 영역을 채우며 기본 오버레이 스크롤바는 숨깁니다.
- 세로 스크롤바는 창 오른쪽 17px 영역에 항상 표시합니다. 위아래 화살표, 트랙 클릭, 손잡이 드래그, 이전/다음 쪽 버튼을 제공합니다.
- 가로 스크롤바는 하단 문서 탭 오른쪽에 항상 표시합니다. 문서 탭을 숨기면 별도 하단 줄에 표시합니다. 스크롤이 필요하지 않은 방향은 비활성 모양을 유지합니다.
- 손잡이는 보이는 영역과 전체 문서 크기의 비율을 반영하며, 여러 쪽 문서에서도 최소 크기를 유지합니다. 확대·축소와 창 크기 변경 시 이동 범위를 다시 계산합니다.
- 문서 탭의 긴 파일명은 정해진 영역 안에서 표시하고 전체 경로는 툴팁으로 제공합니다. 상태 메시지도 제한된 공간 안에서 표시해 오른쪽 확대/축소 조작부를 유지합니다.
- 기존 Ctrl+휠 확대/축소, 일반 휠 이동, 커서 따라가기, 쪽 이동, 고정 눈금자와 셀 여백 조절은 같은 문서 스크롤 상태를 사용합니다. 이 변경은 문서 내용·조판·저장 형식을 변경하지 않습니다.

자동 검증은 고정 위치와 긴 파일명·메시지, 양방향 손잡이 드래그(마우스 누름과 이동이 한 프레임에 들어오는 경우 포함), 화살표·트랙 이동, 스크롤 끝 제한, 탭 숨김, 작은 배율에서 범위 초기화를 포함합니다. 전체 검사 로그: `logs/0.12-tests.log`, `logs/0.12-clippy.log`, `logs/0.12-build.log`.

아래한글의 스크롤바 위치와 배치를 참고한 자체 Rust/egui 구현이며, 운영체제 네이티브 스크롤바나 아래한글 UI 전체의 완전 복제는 아닙니다.

최종 검사: 전체 테스트 **133개 통과**, 기존 무시 2개, Clippy 통과, Windows 릴리스 빌드 성공. 실제 설치본에서 12쪽 HWPX의 세로 손잡이 드래그로 5~6쪽 영역 이동, 200% 확대 상태에서 가로 드래그에 따른 본문·눈금자 이동을 확인했습니다. [세로 이동 화면](../output/scroll-layout/vertical-drag.png), [가로 이동 화면](../output/scroll-layout/horizontal-drag.png). 쪽 이동 화살표는 폰트 글리프 대신 선으로 그려 글꼴에 따른 깨짐을 방지했습니다.
