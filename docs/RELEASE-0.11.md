# HwpCraft 0.11 — 셀 안 여백과 문서 모서리 표시

- 표 레이아웃 탭 및 셀 우클릭 메뉴에 **셀 안 여백**을 추가했습니다. 표/셀 속성의 셀 탭을 바로 열고 상속된 여백을 초깃값으로 사용합니다. 설정을 누르기 전에는 문서를 변경하지 않습니다.
- 셀을 클릭하면 가로 눈금자의 흰 영역과 원점이 해당 셀의 글 영역으로 바뀝니다. 왼쪽/오른쪽 경계 표식을 끌면 셀 안 여백이 바뀝니다. 두 번 클릭하면 상세 설정을 엽니다.
- 눈금자 조절은 현재 셀 또는 선택된 셀 블록에 적용되며 쪽 여백은 바꾸지 않습니다. 한 번에 Undo할 수 있습니다.
- 한쪽 여백만 지정해 셀별 여백 사용을 켜도 나머지 방향의 표 기본 여백을 유지하도록 엔진을 수정했습니다. 좌우 여백 합계가 셀 너비 이상이면 문서를 변경하지 않고 오류를 표시합니다.
- 실제 쪽의 본문 영역에 회색 ㄱ자 모서리 표시 4개를 그립니다. 머리말/꼬리말, 제본 여백, 맞쪽 구성을 엔진의 해석된 쪽 정보로 반영합니다. 화면 안내이므로 PDF·인쇄·HWP/HWPX에는 추가하지 않습니다.

검사: 셀 여백에 따른 글 시작 위치 이동, 다른 방향 상속 보존, Undo/Redo, HWP/HWPX 왕복 저장, 과도한 여백 거절, 실제 눈금자 입력 이벤트와 쪽 여백 불변, 맞쪽 본문 영역 좌표. 로그는 `logs/0.11-tests.log`, `logs/0.11-clippy.log`, `logs/0.11-build.log`입니다.

현재 눈금자에서 직접 끌 수 있는 셀 안 여백은 좌우입니다. 위아래는 셀 안 여백 창에서 입력합니다. 중첩 표의 눈금자 조절은 지원하지 않습니다.

최종 검증: 전체 테스트 130개 통과, 기존 무시 항목 2개, Clippy 통과. 네이티브 설치본에서 눈금자를 20px 끌어 왼쪽 여백이 1.80mm에서 7.69mm로 바뀌고 글 시작 위치가 이동하는 것을 확인했습니다. 다른 방향의 여백은 유지되며 저장 후 다시 열어도 유지됩니다. 50% 배율에서 본문 영역의 네 모서리 표시를 확인했고 표 이동 손잡이를 왼쪽으로 옮겨 표시가 겹치지 않도록 했습니다. 빌드·로컬 실행본·런처 설치본의 실행 파일 SHA-256이 일치합니다.
